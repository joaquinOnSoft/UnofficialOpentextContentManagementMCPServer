# Automatización de la preparación de una demo de Opentext Content Management

Quieres que evalues la opción de reproducir el proceso de preparación de una demo de 
Opentext Content Management descrito en el documento adjunto, y elabores una tabla con la lista de 
llamadas a las APIs para conseguirlo lo mismo que el proceso manual descrito en el documento.

Como formato de salida quiere que generes una tabla con los siguientes campos:

	- Nombre del API
	- Nombre del método del API
	- Nombre del end point
	- Parámetros de entrada
